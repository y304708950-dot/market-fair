# 全国市集活动指南

一个汇集全国各地市集活动的网站，包括农夫市集、创意市集、美食市集、复古市集等多种类型。

🔗 **访问地址**: https://market-fair.onrender.com

## 功能特性

- ✅ **响应式设计** - 适配手机、平板、电脑
- ✅ **多维度筛选**:
  - 📍 地区筛选（省份 → 城市联动）
  - 🏷️ 类型筛选（农夫市集、创意市集、复古市集、美食市集）
  - 📅 时间筛选（今天、本周末、本月、下个月）
- ✅ **关键词搜索** - 支持搜索市集名称、地点、描述
- ✅ **动态统计** - 实时显示筛选结果数量
- ✅ **真实数据** - 基于公开信息整理的真实市集活动

## 数据来源

市集数据来自多个渠道：

1. **手动整理** - 基于公开信息整理的知名市集品牌
2. **活动平台** - 从活动行、大麦网等平台抓取（受反爬限制）
3. **社区贡献** - 欢迎用户提交新的市集信息

## 技术栈

- **前端**: HTML5 + CSS3 + Vanilla JavaScript
- **数据**: JSON 文件存储
- **爬虫**: Python (requests + BeautifulSoup)
- **部署**: GitHub + Render (自动部署)

## 项目结构

```
market-fair/
├── index.html          # 主页面
├── style.css           # 样式文件
├── app.js              # 前端逻辑
├── markets_data.json   # 市集数据（自动生成）
├── scraper.py          # 数据爬虫
├── update_data.sh      # 数据更新脚本
└── README.md           # 项目说明
```

## 数据爬虫

爬虫脚本 `scraper.py` 会从多个数据源抓取市集活动：

1. **活动行** (huodongxing.com) - 活动发布平台
2. **大麦网** (damai.cn) - 票务平台
3. **手动整理** - 基于公开信息的市集品牌

### 运行爬虫

```bash
python3 scraper.py
```

## 提交新市集

欢迎提交新的市集活动信息！

### 提交方式

1. **GitHub Issues** - 提交市集信息
2. **邮件** - 发送到 submit@market-guide.com
3. **网页** - 点击网页上的"提交市集"按钮

### 需要的信息

- 市集名称
- 所在城市
- 详细地址
- 活动时间
- 市集类型
- 简要描述
- 官方网站/社交媒体（如有）
